# Дорожная карта

## ✅ Этап 1 — MVP (веб, один телефон)

- Настройка: 3–12 игроков по часовой стрелке, выбор одной или нескольких категорий, 18+ с проверкой возраста.
- Раздача по кругу с удержанием карточки, подсказка брехлу (опционально).
- Круги ассоциаций, голосование, шанс брехла угадать слово.
- Раунды-сюрпризы: без брехла / все брехло (~1 из 10, не подряд).
- PWA, офлайн, сохранение состояния, кнопка «Установить игру».
- «Напомнить слово» во время раунда.

## Этап 2 — полировка и контент

- Счёт по раундам и итог вечера.
- Свои наборы слов прямо в приложении, обмен набором по ссылке.
- Расширение наборов, голосование «слово плохое» для чистки списков.
- Звук/вибрация, анимация переворота карточки, светлая тема.
- E2E-тесты на Playwright, Lighthouse в CI.

## Этап 3 — нативные приложения

- Обёртка в Capacitor: iOS и Android из той же кодовой базы.
- Нативные хаптики, защита от скриншотов на экране карточки.
- Публикация в Google Play / App Store / RuStore.

## Решения

- **Одно устройство**, без мультиплеера — осознанно: игра для компании за одним столом.
- **Без второго брехла** — превращает игру в командную, это другая механика.
- **Таймера нет** — темп задаёт компания.
- **Счётчика кругов нет** — приложению не нужно знать номер круга, компания решает сама.
